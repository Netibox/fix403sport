URL สตรีม

วิธีแก้ปัญหา 403 Forbidden

ใช้ Proxy / CORS Anywhere
เปิดเว็บ corsproxy.io แล้วใส่ URL สตรีม หรือใช้ extension "Allow CORS" บน Chrome
ตั้งค่า Referer & User-Agent
บางเซิร์ฟเวอร์ตรวจสอบ Referer ให้ติดตั้ง extension "ModHeader" เพื่อปลอมแปลง headers
ใช้ VLC Media Player
คัดลอก URL ไปเปิดใน VLC (Media → Open Network Stream) ซึ่งไม่มีข้อจำกัด CORS
ใช้ Python Proxy
รัน proxy ง่ายๆ ด้วย Python: python -m http.server 8080 แล้วตั้งค่า headers ที่ต้องการ
